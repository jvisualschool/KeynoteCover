# KEYCOVER 기본 복셀 스타일

스타일 참고 이미지는 `app/style-reference.png`에 둔다. 이 파일은 API에 스타일 참고용으로 전달되며, 공개 웹 루트에는 두지 않는다.

- 밝은 아이보리 몸체, 선명한 일렉트릭 블루·시안, 노란 포인트.
- 큼직하고 친근한 복셀 형태, 계단형 윤곽, 깔끔한 넓은 면과 약한 모서리 부드러움.
- 밝은 소프트박스 조명과 충분한 보조광. 탁한 청록·회색, 지나친 무광·거친 표면·검게 뭉친 그림자는 피한다.
- 어두운 배경에서도 물체의 밝기와 채도를 유지한다. 배경색과 투명 여부는 사용자가 선택한 옵션을 따른다.
- 원문에 명시된 물체색과 강의 내용은 보존한다. 참고 이미지의 컴퓨터·마우스 캐릭터·돋보기·구도를 다른 강의에 임의로 넣지 않는다.
- 정투영 아이소메트릭, 무문자, 2560×1440 PNG, 200px 여백 유지.

구상 버전6에서 과거 AI가 추측한 팔레트와 색상 요구를 재사용하지 않고 원문에서 다시 설계한다. 이미지 생성 시 `images/edits`에 참고 PNG를 전송하고 스타일 역할만 부여한다. 참고 원본은 공개 웹 루트에 배포하지 않는다. 새 갤러리 기록에는 참고 파일의 이름과 SHA-256을 남긴다.

API 적용 근거: [OpenAI의 이미지 스타일 참고 지침](https://developers.openai.com/api/docs/guides/image-prompting#transfer-a-visual-style), [이미지 편집 API](https://developers.openai.com/api/reference/resources/images/methods/edit).

## 컬러 테마 선택

블루(기본), 오션, 그린, 선셋, 베리, 모노의 6가지 테마를 제공한다. 밝은 복셀 재질과 조명은 공통으로 유지하고 물체 팔레트만 바꾼다. 배경색/투명 옵션은 독립적이다. 명시된 원문 색과 식별에 필요한 자연색은 보존한다.
구상 버전7에서는 `visual_brief_theme`로 캐시를 구분한다. 테마 변경 시 원문에서 구상을 갱신하며 참고 PNG의 파란색보다 선택 테마가 우선한다. API 검증, 작업 복원, 생성 옵션, 영구 갤러리 상세정보에 `color_theme`를 전달한다. 기존 결과의 저장된 프롬프트와 색상은 변경하지 않는다.
